# Q-Guide

Q-Guide is a mobile-based smart patient queuing system
with geofencing technology for the Outpatient Department
of Eastern Visayas Medical Center.

## Project Components

- mobile_app: Flutter patient mobile application
- backend: Node.js and Express REST API
- staff_dashboard: React staff and admin dashboard
- database: SQL scripts and database documentation
- docs: Setup and testing documentation

## Development Database

The local development database will use the database service
provided by XAMPP.
